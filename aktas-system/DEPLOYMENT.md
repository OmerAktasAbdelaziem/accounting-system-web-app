# Render Deployment Guide for Aktaš Accounting System

## Prerequisites

1. **GitHub Account**: Your repo must be pushed to GitHub
2. **Render Account**: Create free account at https://render.com
3. **Repository**: `OmerAktasAbdelaziem/accounting-system-web-app`

---

## Deployment Steps

### Option 1: One-Click Deploy (Recommended)

1. Go to [Render Dashboard](https://dashboard.render.com)
2. Click **"New +"** → **"Web Service"**
3. Select **"Deploy existing repo"** and choose `accounting-system-web-app`
4. Fill in the settings:
   - **Name**: `aktas-accounting-system`
   - **Runtime**: `Docker`
   - **Region**: `Frankfurt` (or your preferred region)
   - **Branch**: `main`
   - **Build Command**: `composer install --no-dev --optimize-autoloader && php artisan migrate --force && php artisan db:seed --class=TestDataSeeder`
   - **Start Command**: `apache2-foreground`

5. Click **Create Web Service**

### Option 2: Use render.yaml (Infrastructure as Code) - RECOMMENDED

1. Push your code with the included `render.yaml` file
2. In Render Dashboard, click **"New +"** → **"Web Service"**
3. Select your GitHub repo
4. Render will **auto-detect** `render.yaml` and use those settings
5. Click **Deploy** - it will automatically create both the web service AND PostgreSQL database

## Troubleshooting

### "Permission Denied" on storage/ directory
The Dockerfile fixes this automatically. If issues persist, go to **Render Shell** and run:
```bash
chmod -R 755 /var/www/html/storage
chmod -R 755 /var/www/html/bootstrap/cache
```

### Database connection failed
- Verify PostgreSQL service is linked in Render
- Check in Render dashboard: **Services** → **aktas-postgres-db** → **Connection**
- Ensure database firewall allows Render IPs

### Migrations didn't run
In Render dashboard, go to **Web Service** → **Shell** and run:
```bash
php artisan migrate --force
php artisan db:seed --class=TestDataSeeder
```

### Check logs for errors
In Render dashboard, go to **Logs** tab to view real-time application logs.

## Manual Deployment (Without render.yaml)

If you prefer not to use `render.yaml`:

1. Create **Web Service** manually with Docker runtime
2. Create **PostgreSQL** service separately
3. In Web Service, add environment variables:
   - Copy all from the render.yaml file
   - Add the PostgreSQL connection details

But **using render.yaml is recommended** as it's all done automatically!

---

## Using Your Own PostgreSQL Server

If you have an external PostgreSQL server, update environment variables in Render:

```
DB_CONNECTION=pgsql
DB_HOST=your-external-postgres-host.com
DB_PORT=5432
DB_DATABASE=aktas_system
DB_USERNAME=your-username
DB_PASSWORD=your-secure-password
```
